# Catálogo público de clínicas

## Origem e abrangência

Versão 1.2, consulta documental em **24/09/2026**: **20 unidades físicas**, **11 sites próprios**, **3 cidades do Ceará** e as **9 especialidades** reconhecidas pelo MedFinder. O cadastro é uma seleção inicial para desenvolvimento, não um diretório completo de Fortaleza ou do Brasil.

Os fatos abaixo foram consultados nas páginas indicadas. Não foram copiadas fotos, avaliações de pacientes nem prontuários. Não existe integração com API Docplanner, coleta automática em produção ou sincronização de agenda. `verifiedAt` indica a consulta à fonte pública; não significa telefonema, visita, certificação do serviço ou comprovação de disponibilidade.

## Decisões de coleta

- Cada unidade tem um ID estável, endereço, telefone público, especialidades documentadas, fonte HTTPS e data. Telefones são canais comerciais publicados, não contatos privados.
- CLDO e CCO na Rua Ildefonso Albano, 1373 compartilham local e telefone e foram agrupados em um único cadastro; não são contados duas vezes. As demais unidades têm endereços diferentes.
- Nas três unidades Otos foi cadastrada somente otorrinolaringologia, confirmada para cada endereço. A existência de outras especialidades na rede não foi extrapolada a todas as unidades.
- AVA foi mapeada somente para dermatologia. Neurocirurgia não foi transformada em neurologia. Neuropediatria da iClinic não foi transformada em neurologia geral.
- Os nomes de especialidades foram limitados à taxonomia atual. Isso não significa que a clínica não ofereça outros serviços.
- Os convênios de CTI, iClinic e Multiclinic foram publicados nas respectivas páginas. Para CTI, foram transcritos apenas nomes identificáveis; um nome com grafia ambígua não foi normalizado por suposição. Não usamos valores de consulta, disponibilidade nem avaliações como ranking.
- `insurances=[]` significa informação não cadastrada, **não** que a clínica aceite somente atendimento particular. Não foram presumidos convênios a partir de clínicas vizinhas, filiais, profissionais ou listas antigas.
- Convênio no nível da clínica é um vínculo publicado na página, não confirmação para todo médico, produto, procedimento ou modalidade. O usuário deve confirmar cobertura com a clínica e a operadora. Não há parceria comercial do MedFinder declarada por esses cadastros.

## Como carregar e manter

Com a API local parada:

```powershell
npm.cmd run catalog:load
```

O comando lê `data/clinics.public.json`, valida todos os registros e faz a substituição da coleção em uma transação. Não precisa de uma API de clínicas. No modo demo não precisa de nenhuma chave. `setup:local`, `setup:connected` e a inicialização local com `AUTO_SEED=true` também carregam a coleção.

O importador guarda os IDs da coleção em `catalog_collections`, desativa registros retirados da versão e clínicas fictícias, e preserva cadastros manuais fora da coleção. Os dois registros públicos da versão 1.1 são desativados na primeira substituição. A migração também retira de exibição os registros da conexão de API antiga, preservando-os no banco.

Reimportar **não** altera `verifiedAt`. Após 180 dias sem reverificação, um cadastro real sai dos resultados. Para renovar, abra a fonte, confira nome, endereço, telefone, especialidades e convênios; atualize os campos e a data real no JSON. Não altere somente a data para contornar a expiração. Não há um robô realizando essa revisão nesta entrega.

Para acrescentar cadastros independentes, use IDs próprios, sem o prefixo reservado `public-`, `provenance=manual` e:

```powershell
npm.cmd run data:import -- clinics caminho/clinicas-verificadas.json
```

A importação manual é upsert: itens ausentes são preservados. Para desativar, reimporte o mesmo ID com `active=false`. Campos desconhecidos devem permanecer nulos ou vazios. IDs duplicados são rejeitados antes da gravação.

## Relação com RAG e IA

O catálogo fornece fatos cadastrais por SQL, com filtros exatos de cidade, convênio e especialidade. O RAG clínico usa outra coleção: `data/knowledge.demo.json`, oito resumos/adaptações editoriais do NHS sobre pescoço, pele, cabeça, abdômen, ouvido, olhos, costas e ansiedade. Cada um traz sua fonte; os três novos temas foram consultados em 24/09/2026. Todos permanecem `draft`, sem revisor atribuído, e só entram na recuperação quando a base de homologação é permitida.

A geração OpenAI usa os trechos recuperados para orientar a navegação, e o servidor monta os cards exclusivamente a partir do banco. Mais clínicas melhoram a cobertura de atendimento; não comprovam a qualidade clínica das respostas nem substituem avaliação do corpus. As associações brasileiras de especialidade e as regras de alerta precisam de revisão local.
