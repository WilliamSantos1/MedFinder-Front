# Operação — 3.0

Antes de cada demonstração/entrega:

```powershell
npm.cmd run check
npm.cmd run test:e2e
npm.cmd run audit:catalog
npm.cmd run setup:ollama
```

Não edite manualmente a data de verificação para “renovar” cadastro. Não preencha coordenadas, convênios, profissionais ou registros sem fonte. Localização do usuário é temporária; coordenadas das clínicas são dados administrativos auditados.

Em caso de alteração de taxonomia, rode migrações e reimporte o catálogo antes de reindexar RAG.
